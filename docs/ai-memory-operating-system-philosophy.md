# Define AI memory operating system philosophy

This document defines Mnemos as an:

```text
AI Memory Operating System
```

rather than:
- a simple RAG wrapper
- vector database utility
- embedding storage layer

## Core Identity

Mnemos exists to provide:

```text
Persistent Intelligence
```

through structured memory lifecycle management.

## Permanent Core Principles

### 1. Memory is not an AI feature

Memory is:

```text
the foundation of persistent intelligence
```

### 2. AI memory requires lifecycle management

Memory must support:
- capture
- summarization
- compression
- retrieval
- promotion
- archive
- expiration

### 3. Context persistence is mandatory

Long-running AI systems require:
- continuity
- historical awareness
- operational memory
- persistent context

### 4. Retrieval quality is more important than storage quantity

The goal is not maximizing storage.

The goal is:
- meaningful retrieval
- operational relevance
- contextual continuity

### 5. Memory provenance and trust levels matter

Different memory sources require:
- trust classification
- provenance tracking
- confidence separation
- lifecycle policies

### 6. Memory systems must outlive model generations

Mnemos should become:
- model-agnostic
- runtime-agnostic
- workflow-compatible
- ecosystem-oriented

## Foundational Statement

```text
Memory is not an AI feature.
Memory is the foundation of persistent intelligence.
```

This philosophy must guide:
- architecture
- ingestion
- retrieval
- ranking
- summarization
- lifecycle management
